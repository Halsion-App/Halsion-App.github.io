# Halsion website

Static GitHub Pages site (repo `Halsion-App/Halsion-App.github.io`); pushing to `main` deploys https://halsion-app.github.io.

- `privacy.html` must match the in-app privacy policy (iOS `Features/About/AboutContent.swift`, Android `privacy_*` strings).
- `app-ads.txt` holds the AdMob publisher ID; don't change it unless asked.
- Plain HTML and `style.css`, no build step.
